# 测试 SOP 变更记录

## [1.0.0] - 2026-05-13

### 初始版本

- 创建完整测试 SOP 体系，包含：
  - `DEMO-SMOKE.md` — 演示前 15 分钟 Smoke Test
  - `QUICK-CHECK.md` — 日常快速验收（[P0] only，~30min）
  - `FULL-REGRESSION.md` — 完整回归测试（全量，~2h）
  - `DEPLOY-CHECK.md` — 部署后专项检查
  - `MODULE-DEPENDENCY.md` — 模块依赖关系 & 影响范围快查表
  - `KNOWN-PITFALLS.md` — 历史翻车点记录

### 覆盖模块

- M1: 搜索核心（文本搜索 + 以图搜图 + 搜索历史）
- M2: 搜索过滤器（13 种过滤器 + 分类侧边栏 + 记忆）
- M3: 搜索结果展示（Grid/List 视图 + 虚拟滚动）
- M4: 图片加载系统（三级缓存 + 懒加载）
- M5: 资产详情（模态框 + 标签编辑 + Reindex）
- M6: 标签系统（全局标签 + 增删 + 过滤 + 部署验证）
- M7: 目录树（三级 fallback + 路径筛选）
- M8: 认证 & 服务器（Basic Auth + Device Flow + 服务器切换）
- M9: 多选 & 交互（单击/双击/checkbox/拖拽框选/Shift 多选）
- M11: i18n & 视觉一致性
- M12: 部署差异检查

### 特色

- 每个测试项标注 [P0]/[P1] 优先级，支持快速/完整两种执行模式
- 「状态交叉联动」section 覆盖跨模块场景
- 「历史翻车定向回归」[REGR] 标签确保已修复问题不复发
- 模块依赖快查表支持精准定向回归
