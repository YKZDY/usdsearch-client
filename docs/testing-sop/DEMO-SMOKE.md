# 演示前 Smoke Test (DEMO-SMOKE)

> **用途**：演示前 15 分钟必过。全部通过才能开始演示。
> **预计耗时**：~15 分钟
> **环境**：部署环境（非本地 dev），使用隐私模式浏览器

---

## 前置条件

- [ ] 使用部署地址（非 localhost）
- [ ] 使用隐私模式或新浏览器 profile（排除缓存干扰）
- [ ] 网络连接正常（能访问 ov.qq.com）
- [ ] 浏览器控制台已打开（F12 → Console）

---

## Checklist

### 1. 页面加载 & 外观

- [ ] 页面 3 秒内完整加载（logo + 搜索框 + 侧边栏 + 结果区）
- [ ] 界面为中文模式，无英文残留，无 i18n key 暴露（如 `authMethod`）
- [ ] LightArt 品牌 logo 正确显示
- [ ] 深色主题 + 金色 #FFD230 强调色正确
- [ ] 浏览器控制台无红色 Error

### 2. 登录

- [ ] 点击右上角认证入口 → 弹出登录界面
- [ ] 输入用户名/密码 → 点击确认 → 显示"已认证"状态
- [ ] 认证成功后页面无刷新/白屏

### 3. 核心搜索

- [ ] 搜索框输入"建筑" → 回车 → 2 秒内返回结果
- [ ] 结果数量大于 0，显示在结果标题栏
- [ ] 缩略图正常加载（非全部灰色 placeholder）
- [ ] 清除搜索 → 恢复默认结果

### 4. 以图搜图

- [ ] 点击搜索框相机图标 → 选择本地图片 → 返回相似结果
- [ ] （或）拖拽图片到搜索框 → 返回相似结果
- [ ] 图片预览出现在搜索框中
- [ ] 点击预览 X 按钮 → 清除图片 → 恢复文本搜索

### 5. 分类侧边栏

- [ ] 左侧分类列表完整显示（所有产品、建筑、物件…）
- [ ] 点击"建筑" → 结果变为建筑类资产
- [ ] 点击"所有产品" → 恢复全量
- [ ] 二级分类可展开并点击筛选

### 6. 资产详情

- [ ] 点击任意卡片 → 弹出详情模态框
- [ ] 模态框内缩略图正常展示
- [ ] 资产名称、路径、属性信息正确显示
- [ ] 标签列表正确展示

### 7. 标签操作

- [ ] 在详情弹窗中添加一个标签 → 成功添加（列表中出现）
- [ ] 删除刚添加的标签 → 成功删除
- [ ] 关闭弹窗后，卡片上的标签同步更新

### 8. 目录树

- [ ] 登录状态下左侧/路径筛选中目录树正常加载
- [ ] 点击目录节点 → 搜索路径自动填入 → 搜索触发

### 9. 视图 & 交互

- [ ] Grid → List 视图切换正常，无白屏/错位
- [ ] List → Grid 切换回来正常
- [ ] Hover 卡片 → 有视觉反馈（阴影/高亮）
- [ ] 卡片左上角 hover 出现 checkbox
- [ ] 点击 checkbox → 卡片选中 → 底部 SelectionModeBar 出现（无抖动）

### 10. 服务器 & 网络

- [ ] 右上角显示当前服务器信息（instance info 已加载）
- [ ] 无"未检测到服务器"或连接错误提示

---

## 不通过时的处理

- **红色 Error 在控制台** → 截图记录，评估是否影响演示流程
- **标签功能异常** → 检查 wss 连接状态，确认 SERVER_MAPPING 环境变量
- **图片不加载** → 确认认证状态，检查 /image API 响应
- **页面白屏** → 检查环境变量配置、打包产物是否最新
