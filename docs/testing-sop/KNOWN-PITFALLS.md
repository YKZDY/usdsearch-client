# 历史翻车点 & 已知问题 (KNOWN-PITFALLS)

> 持续更新。每次踩坑后记录到这里，避免同样的问题再次出现。
> 发版前必须对照此文件做定向回归。

---

## 标签系统

### Tag 在部署后静默失败
- **根因**：`SERVER_MAPPING` 环境变量为空 `{}`，导致 `selectedBackend="omniverse"` 直接被当作 host 拼成 `wss://omniverse/...`，浏览器无法解析
- **修复**：`config.jsx` 增加 `SERVER_MAPPING_FALLBACK` 兜底映射 + `resolveNucleusHost()` 函数
- **回归点**：每次部署后用隐私模式验证 tag 增删

### Tag 本地正常、线上失效
- **根因**：本地浏览器 localStorage 中有旧的有效 token 缓存，因此本地即使用线上地址也能正常工作；其他用户无此缓存所以失败
- **回归点**：始终用隐私模式测试 tag 功能

### 搜索关键词与标签重复加权
- **根因**：标签选中后同时写入 `q` 字段和 `filter_by_tags`，导致后端 scoring 被双重影响
- **修复**：搜索 payload 中去重标签名
- **回归点**：选中标签后检查搜索结果排序是否合理

## 多选 & 交互

### SelectionModeBar 弹出时页面抖动
- **根因**：横幅插入 DOM flow 导致下方卡片位移
- **修复**：改为覆盖筛选栏（position: absolute/fixed）
- **回归点**：第一次选中卡片时观察卡片是否跳动

### Checkbox 点击区域太小
- **根因**：左上角圆形 checkbox 实际点击区域仅图标大小
- **修复**：增大 clickable area（padding + 透明热区）
- **回归点**：快速点击左上角 checkbox，成功率应 >95%

### 选中后无法查看其他卡片详情
- **根因**：选中模式下所有点击都变成选中/取消，无法打开详情
- **修复**：双击仍可打开详情
- **回归点**：选中一张后双击另一张，应弹出详情

### 选中动画延迟严重
- **根因**：Framer Motion 动画组件开销
- **修复**：简化动画 / 减少重渲染
- **回归点**：快速连续选中 5 张卡片，观察选中反馈是否流畅

### 卡片描边出界
- **根因**：选中态 border/outline 超出卡片容器
- **修复**：使用 box-shadow 替代 border 或设置 overflow
- **回归点**：选中卡片后观察四边描边是否超出卡片边界

### 拖拽多选操作逻辑
- **根因**：默认拖拽行为是选中文本而非框选
- **修复**：空白处拖拽=框选，卡片内拖拽=选文本（模仿 Windows 文件管理器）
- **回归点**：在卡片间空白处拖拽观察是否出现选框

## 认证

### Token 过期提示不明显
- **根因**：使用 toast 通知，用户容易忽略（演示中发生过）
- **修复**：改为弹窗 (Modal) 提示 + 引导重新登录
- **回归点**：模拟 Token 过期（清除 localStorage Token），观察提示形式

---

## UI & 视觉

### z-index 图层错误
- **根因**：模态框/overlay/toolbar 的 z-index 设置不当导致遮挡
- **回归点**：打开详情弹窗时确认背景遮罩正确，toolbar 不浮在弹窗之上

### 搜索栏覆盖导致卡片位移
- **根因**：覆盖搜索栏的提示信息插入 DOM flow
- **回归点**：搜索提示出现/消失时卡片不跳动

---

## 部署

### 假数据残留
- **根因**：dev 环境的 mock 数据或 placeholder 未在 build 中清除
- **回归点**：检查结果中是否有明显的假数据（lorem ipsum、test 等）

### 环境变量未注入
- **根因**：部署时 .env 文件未配置或 CI 未传入环境变量
- **回归点**：打开页面 source，确认 `%REACT_APP_*%` 已被实际值替换
